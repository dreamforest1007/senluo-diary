# 森羅生活｜手機桌面 APP 版（PWA）

## 套件內容
- index.html：整合應用程式（含日記、四象限任務、月曆、財務、目標、健康、購物與收納、番茄鐘、備份）
- app.webmanifest：桌面 APP 名稱、圖示、獨立顯示
- sw.js：APP 外殼的離線快取
- icons/icon-192.png / icon-512.png：手機主畫面圖示

## Android 安裝（需要 HTTPS）
1. 把這個 ZIP 解壓縮，將「裡面的檔案」完整上傳到有 HTTPS 的靜態網站空間（例如 Cloudflare Pages / GitHub Pages）。
2. 使用 Android Chrome 開啟你的 HTTPS 網站網址。
3. 選擇網址列或右上角「⋮」選單中的「安裝應用程式」或「加到主畫面」。
4. 之後即可由手機桌面的「森羅生活」圖示直接啟動，介面將以獨立視窗顯示。

注意：手機直接開啟下載的 HTML（file:// 或 content://）只是預覽，無法直接安裝成正式 PWA。

## 使用限制
- 資料存在該網域的瀏覽器本機儲存，不會自動同步裝置，也不會儲存在伺服器。
- 安裝版與你先前以本機 HTML 開啟的版本，資料儲存區不同；請在舊版「備份與設定」匯出 JSON，再到新版匯入。
- 網站部署完成並首次連線開啟後，主要介面可離線使用；不是雲端同步或真正的原生 Android APK。
- 健康資料為手動紀錄，智慧提醒是本機規則，沒有真正連接 AI、醫院、智慧家電或 SOS 服務。
- 請定期備份 JSON，瀏覽器清除網站資料會造成紀錄遺失。
