安裝森羅生活

把網頁部署到 HTTPS 網址後，使用 Android Chrome 開啟，即可安裝成手機主畫面的獨立 APP。

  1. 以 Chrome 開啟部署好的森羅生活網址。
  2. 點選右上角「⋮」選單，選擇「安裝應用程式」或「加到主畫面」。
  3. 完成後，從手機桌面點選「森羅生活」圖示啟動。

若你現在開啟的是下載的 HTML 檔案（content:// 或 file://），它只能預覽，無法直接變成正式可安裝的 PWA。請使用完整網站套件上傳至 HTTPS 網站。

資料存於該網站的瀏覽器空間，安裝前請先到「備份與設定」匯出舊資料，再到新版匯入。
